2  Crosswalk

UMRS Restoration Features Database Crosswalk to UMRR and NESP Design Terminology

The UMRS Restoration Features database provides a common geospatial vocabulary for documenting, mapping, and managing ecosystem-restoration features across the Upper Mississippi River System (UMRS). It distinguishes between restoration features—such as DredgingEvent, Island, Wetland, Revetment, RiverineFlowStructure, and MoistSoilMgmtUnits—and restoration support features, such as DredgingPlacement, access infrastructure, utilities, stationing, and investigation points.

The database’s purpose is to translate varied project-design terminology into a consistent spatial data structure. A single design action may require multiple mapped database features. For example, a notched closure structure may be represented by RiverineFlowStructure or RiverineFlowStructureLine plus a Notch; an island created with dredged material may include DredgingEvent, DredgingPlacement, Island, and, where applicable, Wetland or Embankment.

This common structure allows UMRR and NESP projects to be mapped, queried, compared, and reported using the same feature classes while preserving each program’s established design terminology. The database does not replace the UMRR Environmental Design Handbook or the NESP Environmental Design Toolkit. Rather, it provides the spatial-data framework that connects their design measures to mapped project components.

Both programs should use the database feature classes as the authoritative mapped term, while retaining the original UMRR or NESP design term as a source attribute, alias, or project-description field.

UMRR

The UMRR Environmental Design Handbook contains detailed terminology for Habitat Rehabilitation and Enhancement Project (HREP) design, including shoreline and riverbank protection, localized water-level management, dredging, river-training structures and secondary-channel modifications, floodplain restoration, island design, aeration, and tributary restoration.

UMRR projects can use the database to convert these detailed design terms into standardized spatial features. For example:

Backwater and secondary-channel dredging can be mapped as DredgingEvent and, when an excavated channel remains, FlowChannel.

Dredged material used for island construction, wetlands, or topographic diversity can be mapped as DredgingPlacement and linked to Island, Wetland, or Embankment.

Closure structures, dikes, weirs, chevrons, wing dams, vanes, and rock sills can be mapped as RiverineFlowStructure or RiverineFlowStructureLine.

Wing-dam notches and notched closures can be mapped as Notch in association with the applicable riverine flow structure.

Shoreline protection and rock revetment can be mapped as Revetment.

Moist Soil Management Units can be mapped as MoistSoilMgmtUnits, with related Embankment, WaterControlStructure, PumpStation, Well, and water-utility support features.

Reforestation, wetland-species planting, and floodplain vegetation establishment can be mapped as FloraPlantingOrSeeding.

Depressional, emergent, and restored wetlands can be mapped as Wetland.

Barrier islands, seed islands, and other constructed islands can be mapped as Island or IslandLine, based on the project’s spatial representation.

Using the database allows UMRR to retain its detailed HREP design history while creating consistent feature-level mapping across projects, pools, reaches, and districts. It also supports analysis of where and how UMRR has implemented individual restoration measures over time. The UMRR handbook specifically recognizes that HREPs often combine multiple techniques to address complex habitat problems; the database captures those combinations as related mapped features instead of forcing the project into one broad label.

NESP

The NESP Environmental Design Toolkit provides planning-level design tools for five principal restoration-feature groups: shoreline stabilization, dredging, river-training structures and secondary-channel modifications, floodplain restoration, and islands. The toolkit uses design pamphlets, drawings, and parametric-cost tools to support early feature identification, alternative development, and plan formulation.

NESP projects can use the database to map proposed and constructed project components consistently with UMRR while retaining NESP’s planning and design terminology. For example:

Shoreline stabilization features, including rock revetments and related protective structures, can be mapped as Revetment.

Dredge cuts, fish-habitat dredging, and access dredging can be mapped as DredgingEvent; excavated conveyance areas can also be mapped as FlowChannel.

Beneficial use of dredged material, including placement for islands, berms, ridge-and-swale topography, or thin-layer placement, can be mapped as DredgingPlacement.

Chevrons, bullnoses, closure structures, guide structures, flow-diversion structures, and other river-training measures can be mapped as RiverineFlowStructure or RiverineFlowStructureLine.

Notched structures can be mapped as Notch and linked to the associated riverine flow structure.

Woody bundles and anchored or locked logs can be mapped as FishStructure when fish habitat is their primary purpose, or as a riverine flow structure when their primary purpose is flow or sediment management.

Potholes, depressional wetlands, emergent wetlands, and vegetation features can be mapped as Wetland and FloraPlantingOrSeeding.

Narrow islands, wide islands, rock-ring islands, seed islands, islands with berms, and islands with emergent wetlands can be mapped as Island, IslandLine, and associated Embankment or Wetland features.

The database gives NESP a consistent mechanism to carry planning-level feature concepts into design, mapping, cost estimating, project documentation, and future performance evaluation. NESP explicitly builds on information from prior UMRS projects and the UMRR Environmental Design Handbook; using the same spatial feature vocabulary supports that continuity.
